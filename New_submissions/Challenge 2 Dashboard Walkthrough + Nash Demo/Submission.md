Challenge 2: Dashboard Walkthrough + Nash Demo
This challenge is a 10-minute, non-coding orientation task for Global Hack Week: Agent Week. Its primary purpose is to familiarize participants with the Backboard.io platform and its unified chat application, Nash, focusing heavily on AI memory retention and multi-model capabilities.

The challenge is divided into two distinct phases:

Part A: The Backboard Dashboard Tour

Participants explore the dashboard's core features, including the analytics fuel gauge (token usage), the model library (housing 17,000+ AI models), the memory management page, and API billing settings.

The Core Task: Participants must test the platform's contextual memory. They are required to feed the built-in chat specific facts about themselves, start a completely new thread, and ask the AI to recall those facts to prove the memory persists across different conversations.

Part B: The Nash Demo

Participants utilize Nash (hellonash.ai), an interface designed to let users interact with various AI models without switching apps.

The Core Task: Participants must initiate a conversation, switch AI models mid-chat to observe how the context history is retained, and test multimodal features (like generating an image or comparing responses between two different models).

Completion Criteria
To officially complete the challenge, participants must submit a single file combining two specific screenshots:

Memory Recall (Part A): A screenshot showing the Backboard chat remembering the provided facts in a brand-new thread.

Nash Interaction (Part B): A screenshot of an active Nash conversation showing a model's text reply or a generated image.
