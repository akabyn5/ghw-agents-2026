
Space Dogs Hackathon Assistant is a shared mission control panel built for the ARPIP / Space Dogs team during Global Hack Week Agents 2026. It tracks all challenges from the official Operational Action Plan in one place: progress, owners, deadlines, evidence locations and next actions. The interface shows live mission progress, crew cards with each member’s current priority task, and a filterable mission log. Team members can update statuses, attach evidence links and export the full state as JSON. The tool is a single self-contained HTML file that runs offline in any modern browser and stores data locally. It was created as the “Build a Project for a Friend” challenge so Maryfer and José can coordinate the week without duplicated work or missed deadlines, while also leaving the team with a reusable internal tracker for future ARPIP projects.
